## 零、上下游职责

| 层级 | 核心目标 | 不承担什么 |
|---|---|---|
| 排盘网页、事实包与回答核验 | 确定性生成盘面事实，根据证据编号自动还原FACT，阻止起点、落点、方向与宫位关系被改写 | 不负责论命解释 |
| NotebookLM上游研究 | 对网页已经确定的FACT调用老师课程解释，按紫微斗数的太极、星情、四化、加减和限运顺序形成可学习的原始素材 | 不负责重新计算盘面关系，也不负责客户文风、篇幅、版式和最终交付形态 |
| Codex下游整编 | 审计NotebookLM原文，保留有效技术内容，处理重复、强弱、生活化表达与交付格式 | 不得为文风顺畅而改写盘面事实或补造新论断 |

上游的措辞可以保留论命力度；是否适合客户阅读，由下游决定。上游硬门槛只针对事实错误、技术链错误、来源错配、语义越级和边界越界。

## 一、这次升级解决什么

v0.11保留v0.10的紧凑证据映射、斗数看盘顺序、C结论、技法检查点与先盲看后校准骨架，并修复完整回归中暴露的解释层偏差：

1. NotebookLM只加载网页导出的`iZiwei Notebook Fact Pack v1`作为唯一盘面源，不再加载含重复摘要的完整v4.1台账；
2. NotebookLM每项证据只输出`E编号=事实编号`，例如`E01=Z054`；网页根据当前事实包自动还原完整FACT，不再要求模型抄写长行；
3. 一个E只绑定一个事实编号。技术关系只存在于网页还原的FACT中，解释正文只引用E编号，避免自然语言再次把方向写反；
4. 每个问题答完立即粘贴到网页“回答核验”。网页区分引用核验、已经实现的核心闭包和尚待人工审查的语义角色，不再把单一PASS理解为论命正确；
5. 大限继续只读取DA、DA-L及相应四化原子编号；D02只作当前限摘要；
6. 同一路径只去重结构计数，不得删去路径内部并存的禄权科忌与自化；限制主题数量，不限制完成主题内部加减所需的证据数量；
7. 正文改为结论主导：每个主题先讲结论，再写命理推演和加减边界；证据映射统一置于回答末尾；
8. 每轮使用显式状态头交接当前题，CP允许报告关键事实遗漏，下游发现上游冻结冲突时可以退回重审。
9. 四化只先说明作用方向和主题激活，不自动等于奖项、名校、证书、收入、升职、破财、官非或疾病；具体结果必须另过语义落点门槛；
10. 一旦选择某个现实主题，必须把同一主题内会支持、改向、减力或反证的材料取全，不能先立强结论再把相反条件写成无关紧要的“更辛苦”；
11. 问题10至12新增“形式兑现与替代兑现”比较，防止把化科一律写成正规学历、把化禄一律写成现实获利、把化权一律写成职位权力、把化忌一律写成客观损失。

本清单仍然是“进阶单盘总研究”。报告年份只在问题12承担当前阶段收束；需要细论单一年份时，另用[[紫微单盘-流年专题提问清单-v0.1]]，不要在本流程继续扩写。

## 二、运行原则

### 1. 三类编号不得混淆

| 类型 | 格式 | 性质 |
|---|---|---|
| 盘面事实编号 | M、B、Z、R、BS、F及四化原子编号、S、D、DA、DA-L、LY、Y | 只来自网页NotebookLM事实包，不得新增或改写 |
| 分析结论编号 | `C题号-序号`，如C2-01 | NotebookLM在本轮建立的可审计判断，不是盘面事实 |
| 阶段检查点 | 网页逐题事实验收与CP-A/B/C/D的M技法检查点 | 网页只核FACT忠实度，M只整理已有C，不得产生新结论 |

每个C结论必须保存：最小命题、盘面编号链、主解释来源系列、斗数论证链、独立合参结构、减力或相反证据、时间层级、现实条件、判断边界和当前状态。

C结论状态只允许：

- `盲看保留`：当前证据足够，但尚未得到现实验证；
- `现实支持`：用户明确事实支持原判断；
- `降级`：只保留更小范围；
- `删除`：证据不足或与现实冲突；
- `待验证`：存在竞争解释，资料暂时不足；
- `事后假设`：看到现实后才出现，不得进入最终素材。

上述是现实校准状态。每个CP检查点另设技术状态：

- `VALID`：已实现网页核验层、主方法链、直接引用、太极范围和语义层级均通过，可暂时冻结；
- `PENDING_SOURCE`：盘面链存在，但没有直接知识来源支持具体解释，只能留作待核记录；
- `FACT_BLOCKED`：台账字段被错读、改写、继承或混入台账外事实；该C立即失效；
- `SCOPE_BLOCKED`：转换太极、第三人范围、医学法律财务边界或时间粒度越界；该C立即失效；
- `MISSING_MATERIAL_FACT`：已选主题遗漏会改变方向、强度、表现方式或成立条件的重要FACT，退回原题补论；
- `ROLE_BLOCKED`：FACT存在，但在正文中被解释成错误宫位、时间层或支持/减力角色；
- `UPSTREAM_CONFLICT`：下游发现已冻结的上游结论与FACT或角色冲突，暂停并退回上游重审；
- `MERGED`：与另一C是同一最小命题或同一因果路径，指向被保留的主C，不再单独计数。

只有`VALID`可以进入后续CP有效结论表。`PENDING_SOURCE`单列待核，不得在后续检查点自动升级；`FACT_BLOCKED`或`SCOPE_BLOCKED`不得换词复活。任一网页核验`BLOCKED`的回答必须整题返工，不能进入相应M技法检查点。

所有CP中的“不增加新判断”只禁止临场补造新的论命结论，不禁止发现遗漏与角色错配。CP可以输出`MISSING_MATERIAL_FACT`、`ROLE_BLOCKED`或`UPSTREAM_CONFLICT`并退回原题；这属于完整性验收，不属于新增判断。

### 2. FACT读取与网页验收规则

NotebookLM只读取事实包中的自描述FACT行。每行已经包含案例、指纹和完整字段，不依赖表头或前后文补全。

| 要说明的事实 | 唯一优先来源 |
|---|---|
| 某颗星、旺陷、生年标记、离心或向心标记 | Z编号 |
| 对宫、三合与三方四正 | R编号 |
| 单条宫干、大限或流年四化 | `Fxx-L/Q/K/J`、`Dxx-L/Q/K/J`、`DAxx-L/Q/K/J` |
| 生年四化 | BS编号 |
| 离心与向心的完整起落 | S编号 |
| 大限及流年叠宫 | DA、DA-L、LY编号 |
| 宫位身份、干支、大限年龄与命身来因标记 | B编号 |

全部C完成后统一建立紧凑证据登记，一行只写一个映射，避免登记信息打断正文：

```text
证据登记：
E01=Z074
E02=R11
E03=F11-K
```

- 事实编号必须来自当前事实包；NotebookLM只负责选择证据，网页负责把编号还原为当前CASE与FP下的完整FACT并核对。
- 同一道回答中的E编号全局通用：同一事实再次使用时沿用原E即可，不必重复登记；同一E不得绑定不同事实。不得在同一行列多个编号，不得把摘要、宫位或星曜说明写进映射行。
- 本题看盘路径、标题技术副标题与解释正文都只引用E编号；宫位、星曜和现实主题名称可以保留，但不得出现B/Z/R/F/S等盘面编号或重抄飞化方向。
- 解释正文写“依据E02，该关系在老师方法中……”；不得再次写两个B编号之间的飞入、冲、对宫、三合、向心或离心。
- 知识课程引用仍按原方式直接引用，不登记为E。正文不得直接出现盘面编号；需要增加事实时先新增一个E映射。
- 每道问题回答后立即粘贴到网页“回答核验”。只有题面要求且网页已经实现的核验层全部PASS，才能暂存该题C结论并进入下一题；BLOCKED时本题作废并重答。网页尚未实现的语义角色与技法正确性继续保留人工审查，不得因“引用通过”自动冻结。

### 3. 斗数论证链与时间层分开

每条判断先还原为一条斗数论证链：

```text
本题太极点与宫位网络 -> 星情呈象 -> 四化起点、落点与方向 -> 自化或向心怎样改变 -> 限运是否承接
```

- 同一因果路径只按一个独立结构计数，不把星曜、四化和自化拆成多票抬高置信度；但去重只作用于计数，路径内部所有会改变含义的组成FACT必须完整登记并参与加减。同一SOURCE/TARGET同时存在不同四化时不得只保留其中一种。
- 多宫合参时，各宫星曜仍保持原B编号归属，不得把参与同一题的星曜合并成“同宫”。写“同宫星曜”时绑定对应Z编号；写“对宫、三合、三方四正”时绑定R编号；写“飞入、飞出”时绑定对应四化原子编号；写离心或向心完整起落时绑定S编号。星曜不在对应Z记录的宫位时，禁止写成该宫同宫星曜。
- 同一星曜若起点、落点、方向、人事宫职或时间作用不同，并且确实改变命题含义，可记为同一主链中的新节点；不得一律合并，也不得一律当成独立证据。
- 一条来源明确、条件完整的本命结构链，可以形成有限的性质或倾向判断；不必为了凑两份证据而拼接无关宫位。
- 稳定机制或较强判断，需要另一条相对独立的支持路径。完成减力检查只说明没有忽略反证，不能代替支持证据，也不能提高置信度。
- 具体事件必须同时具备本命承载、限运触发和现实条件；三层同向也只是提高兑现可能，不保证已经发生。
- 同一结构跨原局、大限、流年重复出现，记录为时间承接完整度，不作为多份独立结构。
- “科忌交叠、禄忌交叠”等应按实际化象命名；只有两个独立的化忌结构才可称“双忌”。同一结构在两个时间层重复，只写“本命结构被大限或流年再次承接”。
- 空宫不等于弱、没有或不重要。遇空宫时必须按主方法链说明是否借对宫、怎样看三方四正、宫干四化和辅煞，各层分别负责什么；来源未给借宫规则时标记PENDING_SOURCE，不自行借星。

### 4. 语义阶梯不得越级

```text
盘面事实 -> 结构倾向 -> 可观察行为 -> 当前现实 -> 具体事件
```

每跨一级都需要论证链中新增且能改变语义的节点、相对独立的合参结构，或用户明确提供的现实事实。盘面只支持“有主见”时，不能写成“听不进意见”；只支持“重视财务”时，不能写成“有钱”或“能兜底”。

### 5. 主题闭包与四化语义

先选现实主题，再完成该主题的材料闭包。闭包不是把整盘全部重抄，而是把会改变这个主题方向、强度、兑现方式或成立条件的事实分成四类：

| 角色 | 必须回答什么 |
|---|---|
| 支持 | 哪些结构直接支持当前命题 |
| 改向 | 哪些结构使它从正规路径转为替代路径，或从外在结果转为内在体验 |
| 减力 | 哪些结构只降低强度、稳定性或持续时间 |
| 反证 | 哪些结构与当前命题相反，足以让结论降级或并列竞争解释 |

同一事实只能按它在本题中的实际角色使用。相反结构不得一律降格为“过程更辛苦”；如果它会改变兑现方式，就必须列为改向；如果它足以推翻主结论，就必须列为反证。缺少会改变结论的材料时标记`MISSING_MATERIAL_FACT`，角色错配时标记`ROLE_BLOCKED`。

四化的默认语义只到主题和作用方向：

- 化禄：增加意愿、资源、接触、流动或获得感，不自动等于收入、利润或现实拥有；
- 化权：增加推动、承担、控制、竞争或压力，不自动等于职位、领导权或执行成功；
- 化科：增加评价、可见度、文书、整理、缓冲或认可主题，不自动等于名校、奖项、证书、考试通过或社会成名；
- 化忌：增加执着、阻滞、亏欠、反复或代价，不自动等于破产、分手、诉讼、疾病或确定损失。

从四化主题升级到现实结果，至少还要有与该结果相匹配的宫位职能、星情或结构承载、相对独立的支持路径、相应时间触发，以及现实条件；盲看阶段缺少现实条件时只能形成可证伪候选，不得写成既定结果。同一结构在原局、大限、流年重复，只增加时间承接，不增加独立结构数，也不得写成“双重能量”后直接抬高事件等级。

### 6. 单一连续对话的隔离规则

本清单在同一条NotebookLM对话中完成一个案例，不要求为不同阶段新开对话。

- 问题0只开启当前案例的唯一[LOCKED-FACTS]事实包，关闭完整台账、原始文字盘、其他案例与课程来源。
- 问题0通过后固定记录：`ACTIVE_CASE=当前案例编号`、`ACTIVE_MODE=E`、`MODE0_STATUS=PASS`。同一案例后续问题1至15及CP检查点均继承该状态。
- `MODE0_STATUS=PASS`后，除非用户明确写“重新执行问题0”或更换案例，NotebookLM不得自行回到模式0，不得重发台账摘要，不得要求重新选择模式。
- 如果某轮误答为模式0，该轮视为无效路由，不改变ACTIVE_MODE、既有C结论或CP检查点；直接重发当前问题即可。
- 问题0通过后，当前事实包始终开启；课程按题开启；完整台账、原始文字盘与其他案例始终关闭。
- 每个阶段检查点重新声明案例编号、指纹与当前有效C编号。
- 每道正式问题开头附上短状态头：`CASE / FP / PREVIOUS_Q / WEB_STATUS / CURRENT_Q / ENABLED_SOURCE_SET`。它是当前任务回执；与旧对话冲突时以状态头为准，只执行CURRENT_Q。
- 更换案例时，优先清除聊天历史；若界面无法清除，先执行“历史重启协议”。仅取消旧来源不能消除旧回答的上下文影响。
- 历史重启后若仍出现旧案例编号、人物、宫位或事件，立即阻断；该案例应改用独立笔记本，不再依靠提示词隔离。

历史重启协议：

```text
现在更换案例。此前对话中的所有案例编号、盘面指纹、C结论与CP检查点全部失效，不得作为本案事实、证据或类比材料。

本轮只读取当前唯一勾选的[LOCKED-FACTS]事实包并重新执行问题0。若回答出现旧案例编号、旧指纹、旧人物、旧宫位或旧事件，立即停止并标记“历史串案风险”，不得继续论命。
```

### 7. 每轮统一斗数论证闸门

以下短协议已经写入问题1至12。不得因为自定义提示词中已有相似规则而删除：

```text
输出前执行斗数论证闸门：每条使用C题号-序号，先写“现实主题 / 本节回答 / 先讲结论”，再写“本题太极点 / 主方法链与直接引用 / 星情与四化解释 / 主题闭包 / 加减与边界 / 独立结构数 / 时间承接层 / 语义层级 / 最小充分结论 / 技术状态”。正文约六至七成用于讲清现实机制、常见表现和成立条件，约三至四成用于命理推演、资料引用与边界。全部C完成后统一输出证据登记，一行一个“E编号=事实编号”；同一道回答中的E编号全局通用，同一事实沿用原E，同一E不得绑定不同事实。正文只引用E编号，不出现盘面编号，也不重新口述SOURCE、TARGET、飞入、冲、对宫、三合、向心或离心。非显然转换必须由相应FACT与来源条件共同支持。同一路径只去重计数，内部并存FACT不得删减；同一结构跨时间只增加承接层，不得用“双重、三重”抬高事件等级。一个C只允许一个主方法链；定义、减力或反证来源不得补齐主链。四化先按主题语义解释，若结论落到学历、奖项、证书、收入、职位、资产、关系事件、疾病或损失，必须另列结果承载、独立支持、时间触发、现实条件与不成立条件，缺一即降回候选范围。回答完成后必须经网页已实现核验层验收；转换或范围缺链标记SCOPE_BLOCKED，关键事实遗漏标记MISSING_MATERIAL_FACT，角色错配标记ROLE_BLOCKED。盲看阶段禁止现实完成时、确定事件和第三人客观事实。
```

每条C开头使用以下紧凑格式，避免技术论证写完后才让读者知道在讲什么：

```text
C题号-序号【现实主题】（主要斗数结构）
本节回答：一句话说明本节辨认什么。
先讲结论：用足够篇幅说明现实机制、常见表现、成立条件与主要分歧。
```

### 9. C结论必须有阅读导航

每条C结论的标题先写它回答的现实主题，再把宫位、星曜与飞化结构放在括号中作为技术副标题。格式固定为：

现实主题应使用“意见听取、危机决策、表达说服、组织角色、执行风格、机会来源、事业卡点”等读者可以直接辨认的词。不得只用宫位名、星曜名、四化链或格局名充当标题，也不得把“初始太极、星情呈象、四化起落”等论证步骤写成并列小标题后才在段尾揭示本节主题。

标题和“本节回答”只负责导航，不代替论证。随后仍按斗数论证闸门完整输出宫位网络、星情、四化、加减、语义层级与最小充分结论。标题主题必须由本条实际证据链决定，不得为凑目录预设结论。

看盘路径只呈现可复用的技术顺序，不展示冗长思考过程，不复述整张台账，也不把课程讲义大段搬入回答。这样用户能够学习老师怎样起手、怎样追四化、怎样做加减，而不是只拿最终断语与现实对答案。

### 10. 审计结果不得在检查点复活

## 三、来源路由
